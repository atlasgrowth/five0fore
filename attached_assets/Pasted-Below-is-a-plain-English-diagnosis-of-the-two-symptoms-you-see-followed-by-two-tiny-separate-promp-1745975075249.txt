Below is a plain-English diagnosis of the two symptoms you see, followed by two tiny, separate prompts you can hand to the Replit agent.
Run Prompt 1 first (bay colours), verify; then run Prompt 2 (Closed tab). No other files touched.

1 Why the bay cards never change colour
When you place an order we correctly set bay.status = "NEW".

Every later status change (COOKING / PLATING / READY / SERVED) updates the order rows but never re-evaluates the bay.

The card component relies solely on bay.status, so it stays blue forever.

Minimal fix
After every markFired, markReady, markServed, call recalcBayStatus(bayId)
– The helper looks at all non-closed order items for that bay and sets:


Rule	Resulting bay.status
≥1 NEW items	NEW
none NEW, ≥1 COOKING	COOKING
none NEW/COOKING, ≥1 PLATING	PLATING
all items READY	READY
no active items	AVAILABLE
Broadcast bay_updated WS message (your client already listens).

Map status → colour in BaySelection.tsx.

2 Why “Close order” never moves the ticket out of Served
The close button calls POST /api/order/:id/close, but that endpoint never changes the status (it only sets closedAt).

The Served tab filters status === "SERVED" so the row never leaves.

Closed tab filters status === "CLOSED" but the enum doesn’t include "CLOSED"—it silently discards everything.

Minimal fix
Add "CLOSED" to the OrderStatus enum and Drizzle schema.

In markOrderClosed set status = "CLOSED" and closedAt = now.

Closed tab fetches status=CLOSED; Served tab stays status=SERVED.

All Active count = every order whose status ∈ {NEW, COOKING, PLATING, READY, SERVED} (but not CLOSED / CANCELLED).

+       .where(and(eq(orders.bayId, bayId),
+                  notInArray(orders.status, ["CLOSED","CANCELLED"])));
+
+    const s = rows.map(r=>r.status);
+    let bayStatus:"AVAILABLE"|"NEW"|"COOKING"|"PLATING"|"READY"="AVAILABLE";
+    if(s.includes("NEW"))           bayStatus="NEW";
+    else if(s.includes("COOKING"))  bayStatus="COOKING";
+    else if(s.includes("PLATING"))  bayStatus="PLATING";
+    else if(s.length && s.every(x=>x==="READY")) bayStatus="READY";
+
+    await db.update(bays).set({status:bayStatus}).where(eq(bays.id,bayId));
+    const bay = await db.query.bays.findFirst({ where:eq(bays.id,bayId) });
